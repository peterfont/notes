# 单篇笔记发布检查表

> 状态：待检查

## 发布前

- [ ] 选题对应明确的人群和具体场景
- [ ] 标题包含用户能理解的结果、痛点或问题
- [ ] 封面 1 秒内能看懂主题，不依赖正文解释
- [ ] 开头兑现标题承诺，没有长篇铺垫
- [ ] 正文有真实经历、案例、数据或明确方法
- [ ] 结尾给出自然的互动动作或下一步
- [ ] 已检查错别字、事实、图片和排版
- [ ] 关键词自然出现在标题、正文或图片文字中

## 发布时

- [ ] 记录日期、时间、选题、标题版本和封面版本
- [ ] 记录内容类型：经验、教程、案例、观点或产品
- [ ] 标签与内容和目标用户相关
- [ ] 发布后及时查看首轮评论并正常回复
- [ ] 不使用违规或过度承诺的引流表达

## 发布后 24 小时

- [ ] 记录曝光、点击/观看、停留、点赞、收藏、评论、涨粉和咨询
- [ ] 把高质量评论整理为后续选题
- [ ] 只记录一个最值得验证的改进点
- [ ] 不因早期数据直接删除或否定内容
