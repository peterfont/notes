# 服务交付与案例沉淀模板

## 交付前

- [ ] 明确客户目标和验收标准
- [ ] 确认服务范围、时间、价格和沟通方式
- [ ] 列出客户需要提供的账号、素材、数据或权限
- [ ] 记录交付前的基线：原有数据、流程和主要问题

## 交付中

- [ ] 每个阶段都有明确产物
- [ ] 记录关键判断、修改原因和客户反馈
- [ ] 发现超出范围的需求时，单独确认是否追加
- [ ] 保留过程截图、版本和结果数据

## 交付后

- [ ] 对照验收标准确认结果
- [ ] 记录客户实际获得的变化
- [ ] 收集可公开使用的反馈或授权
- [ ] 约定复盘、维护、续费或后续服务
