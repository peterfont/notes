# 评论、私信与咨询转化流程

> 状态：待检查

## 第一步：识别需求

- [ ] 区分普通互动、信息咨询、明确购买意向和合作需求
- [ ] 记录用户来自哪篇笔记、关心什么问题
- [ ] 判断是否属于目标客户，不对所有人使用同一套话术

## 第二步：追问情况

建议先确认：

- 你现在遇到的具体问题是什么？
- 已经尝试过哪些方法？
- 希望达到什么结果？
- 时间、预算或使用条件是什么？

## 第三步：给出判断

- [ ] 先复述用户问题，确认双方理解一致
- [ ] 给一个有帮助的初步判断，不急着报价
- [ ] 明确说明能解决什么、不能解决什么
- [ ] 对不适合的需求直接说明，不强行成交

## 第四步：报价与承接

- [ ] 说明交付内容、周期、边界和价格
- [ ] 说明客户需要提供的资料和配合方式
- [ ] 约定下一步动作和回复时间
- [ ] 记录线索状态：新线索、已沟通、已报价、成交、未成交
- [ ] 遵守平台关于引流、联系方式和营销表达的规则

## 第五步：复盘

- [ ] 每周整理高频问题
- [ ] 把重复问题变成笔记或 FAQ
- [ ] 记录用户没有购买的主要原因
- [ ] 记录成交客户最终购买的真实理由
