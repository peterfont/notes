# 账号主页与置顶笔记检查表

> 状态：待检查

## 账号基础

- [ ] 头像能体现真人、品牌或专业身份
- [ ] 昵称容易搜索、记忆，并与内容方向一致
- [ ] 简介说清楚“我是谁、帮谁、解决什么问题”
- [ ] 简介没有夸张承诺、违规引流或无法证明的结果
- [ ] 已补充真实经历、案例、产品或服务证明
- [ ] 主页最近内容能看出稳定的内容主线

## 置顶内容

- [ ] 置顶 1：自我介绍和定位
- [ ] 置顶 2：代表性案例、实测或结果
- [ ] 置顶 3：服务/产品说明或常见问题
- [ ] 每篇置顶笔记都能独立看懂
- [ ] 看完置顶内容后，用户知道下一步如何咨询

## 承接检查

- [ ] 从一篇笔记进入主页后，定位没有断裂
- [ ] 内容中的承诺与主页中的服务一致
- [ ] 私信入口、咨询方式和平台规则保持一致
- [ ] 每月复查一次简介和置顶内容
